# SIEVE

SIEVE turns video into behavioral measurements using interpretable
signal-processing tools, and its value is the speed of the tuning loop: drag a
slider, watch the graphs refill faster than the video plays.

## Running it

`SIEVE.py` at the root opens the window — double-click it, or run it from any
shell. It needs [uv](https://docs.astral.sh/uv/) and a Python to open the file
itself (any one — uv owns the interpreter the app actually runs on): no venv
to activate, no install step first.

The window opens on the projects in whatever directory you launched it from, so
run it from the folder your `.sieve.yaml` projects are in. The headless half is the
`sieve` command (`uv run sieve --help`), which is what a cluster node runs and
never imports Qt.

## The derived indexes

Four files are generated by `scripts/doc_index.py` from the documents they
describe. Don't edit them — change the source file and rerun the tool
(`uv run python scripts/doc_index.py`; `--check` exits 1 if any is stale).

- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — what is settled: one line per
  ADR under `docs/adr/`, taken from the ADR's first paragraph.
- [docs/SCAFFOLD.md](docs/SCAFFOLD.md) — where a module goes, each annotation
  taken from that module's docstring's first line.
- [docs/todo/.index.md](docs/todo/.index.md) — the work items in the order
  `--next` selects them; the next thing the loop does is the first `open` row.
- [docs/findings/.index.md](docs/findings/.index.md) — one row per measurement,
  newest first, verdict standing alone; the `## Loop` section is
  `docs/findings/loop/`, which holds truths about how the work loop fails
  rather than about the system.

Written by hand, and binding: [docs/VISION.md](docs/VISION.md) for the target
and [docs/PLAN.md](docs/PLAN.md) for the sequence.
