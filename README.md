# SIEVE

Signal Isolation for Ethological Video Events (SIEVE) isolates behavior from
video using interpretable signal-processing filters rather than a trained model.

This branch is a rewrite from scratch. `HANDOFF.md` is the only document needed
to build it, and §8 there points at the two previous implementations — read
those for measurements, not for how anything should be shaped.

Setup, commands, and test layout are documented once they exist.
