# SIEVE Capabilities

This is a running list of things SIEVE is capable of, or will be capable of. An item might imply other capabilities, and other capabilities might need to be present for it to be checked off, but that's not the purpose of this list.

This file serves as a history, to-do list, and oracle.

This is the list of what it means for SIEVE to be done!

### Basic capabilities

- [ ] Open video files, play them, and scrub around. A video file needs no pipeline to be interacted with.
- [ ] Auto loop over a period of time.

### Tool authoring capabilities

- [ ] A tool is not SIEVE. SIEVE exists to enable the tools.
- [ ] A tool lives in one file. One file can make multiple tools (where appropriate).

### Tool capabilities

- [ ] Tools auto register to the GUI.
- [ ] Tools can be run from the CLI.
- [ ] Tools have a number of outputs they can make. These can be made as files, or hooked up to other tools as inputs.
- [ ] Tools can optionally have representation in the canvas.
- [ ] Tools have a settings screen to help the user with everything they need to use the tool.
- [ ] Tools report their latency as a bar at the bottom of their card.
