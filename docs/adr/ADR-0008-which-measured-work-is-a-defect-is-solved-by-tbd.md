Nothing in a number says whether it is a price or a mistake, and which
categories of waste are finite and drivable to zero has candidates and no
measurement.

What the tree does now: cost is reported and never listed for fixing; waste is
counted against zero, named as a frame decoded twice, a fetch a declaration
predicted (ADR-0006), a value recomputed that was stored, and a render of a
superseded state. Work discarded on purpose is cost — a coarse preview thrown
away for a better one is a choice with a stated reason — and unattributed time
reads as an incomplete instrument rather than a performance problem.

## Candidates

Poppendieck's seven wastes of software development (*Lean Software
Development*, 2003) — Ohno's muda as named categories each driven to zero, with
no target on work that adds value. Would have to be measured on the claim
already made, that the four named categories reach zero; `predicted` is counted
on the orchestrator shelf already, so the experiment exists in outline.

Muratori's non-pessimization — the line between chasing a target and simply not
doing work that never needed doing. Closest to the wording here, and would have
to be checked against the speculation carve-out, which Lean would call
overproduction and this does not.

Brooks's essential and accidental complexity (*No Silver Bullet*, 1986) — the
same split at design rather than runtime. Listed as the ancestor and probably
loses: it names the distinction and gives an instrument nothing to count.

## Rejected

A fixed performance budget cautionary tale: RAIL's 100 ms and 16 ms are figures
content growth exceeds, so the practice manufactures optimisation work with no
terminating condition — and here three of the four things that would exceed one
move the cost class instead, which is what a class is for.

Google SRE's toil budget cautionary tale: right taxonomy, wrong refusal — a
waste category held under 50% rather than at zero is one somebody has agreed to
keep producing.

Cost-as-a-target cautionary tale: contradicts ADR-0007, where a class belongs to
the pairing and a slower machine falls back deliberately rather than chasing a
figure set on other hardware.
