# archive

Documents that were true while something was being done, and are kept after it
was done because the doing turned up more than the result did.

Nothing here describes the tree as it is. A plan records what somebody meant to
do and what they found out on the way; once the work has landed, the code and
the checks are the state, and a plan left sitting in `docs/` beside them would
be a second description that cannot be kept honest and would quietly be read as
the first.

So the rule is the one every long-lived document in this tree follows, applied
to a whole file rather than to a line: **a claim about current state belongs
where a later measurement can supersede it.** An archived document's claims
cannot be superseded, because nobody is going to re-run it — so it is marked as
archival at the top, dated in its filename, and moved out of the way of anyone
reading `docs/` to find out how things are.

What is worth keeping from one of these usually wants promoting rather than
citing: a decision that is still load-bearing belongs in an ADR, and something
that cost real work to learn belongs in a finding. Neither is minted from here
automatically — both are suggested and never written unprompted — so an
archived file naming what it thinks should be promoted is doing the right
amount.
