decisions:
  - what: the benchmark session selects by `-m benchmark`, not by `--benchmark-only` alone
    why: that flag *skips* non-benchmark tests, so a session with no checks left reports green on 181 skips; `-m benchmark` collects nothing and exits 5 instead
  - what: NO_TESTS_COLLECTED removed from both sessions
    why: the suite is no longer "being built out", and forgiving exit code 5 is exactly what let an empty gate pass
  - what: elapsed time is stamped inside the `frame_changed` slot, not after `qtbot.waitUntil` returns
    why: waitUntil polls on a 10 ms interval, which would be a tenth of the scrub_settle budget of invented latency
  - what: a local Protocol for the `benchmark` fixture instead of `pytest_benchmark.fixture.BenchmarkFixture`
    why: the plugin ships py.typed with no annotations, so strict pyright rejects the call; declaring the one method used states the dependency rather than suppressing it
  - what: assert against the budget on the 160x120 fixture anyway
    why: catching an order-of-magnitude regression does not require the reference footage, and a check that only runs on one machine's media is a check that does not run

rejected:
  - what: reading the elapsed time from benchmark.stats
    why: >
      --benchmark-disable leaves stats empty, so the assertion would silently
      vanish from `nox -s checks` — the session that actually runs on every change
