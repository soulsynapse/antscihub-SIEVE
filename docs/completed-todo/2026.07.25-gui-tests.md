# GUI tests

Checked by mutation. Breaking the editor guard, the letterbox offset, or the
rename's undo push each fails a test — which is the only evidence that any of
these 85 are load-bearing.

## What changed outside the tests

**`VideoView` mapping methods went public.** `_content_rect`, `_to_source` and
`_to_widget` are now `content_rect`, `to_source` and `to_widget`. Not a
concession to the tests: the letterboxed mapping between widget pixels and
source pixels is the widget's service to its callers, and box-dragging will
need it for hit-testing. Testing it directly is a consequence of that, not the
reason for it.

**The `gui` marker was inert.** `tests/gui/conftest.py` declared
`pytestmark = pytest.mark.gui` and nothing was marked. pytest reads
`pytestmark` from test modules and classes only — never from a conftest — so
`-m gui` had been selecting nothing and `-m "not gui"` had been excluding
nothing. The marker is now declared per module, and the conftest carries a
comment saying why, because the failure mode is silent in both directions.
