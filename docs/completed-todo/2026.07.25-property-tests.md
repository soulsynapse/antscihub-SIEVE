# Property tests or drop Hypothesis

The four invariants named in the TODO item, each stated over generated input
rather than examples:

- `ROI.clamped_to` lands inside the frame with positive extent, is idempotent,
  and never grows the region.
- `ROI.from_corners` is corner-order-independent, and produces the *tight*
  bounding box rather than merely a containing one.
- `ScrubPolicy.snap` is idempotent, lands on a multiple of the stride within
  half a stride of the target, and is the identity in exact mode and whenever
  the user has forbidden degradation.
- `ReplicateSet.next_default_name` never collides — with existing names, with
  its own prior output when drawn repeatedly, and it always picks the lowest
  free number.

## What the properties caught

`_DEFAULT_NAME_PATTERN` was `^Replicate (\d+)$`, so a hand-typed
`"Replicate 01"` matched and retired the number 1. The next default then
became `"Replicate 2"` while `"Replicate 1"` was still an unused name — the
docstring's "lowest unused" was false for any set containing a zero-padded
name. Narrowed to `([1-9]\d*)`. No collision was ever possible, which is why
the example tests missed it: the failure mode is a skipped name, not a
duplicate one.

The bound on `clamped_to`'s fits-inside property is also a finding of sorts.
It cannot hold for a 0x0 frame — `clamped_to` resolves the conflict between
"inside the frame" and "positive extent" in favour of extent, returning a
1-pixel ROI that does not fit. That is the right call for a function reached
from paint and edit paths, where raising is worse, and nothing in the system
asks an empty frame for a crop. The strategy therefore starts frame dimensions
at 1 and the test says why.

## What was checked by mutation

Each mutant was applied to `src/`, the corresponding property file run, and the
mutant reverted:

| Mutation | Caught by |
| --- | --- |
| `clamped_to` drops the left/top clamp | `test_clamped_to_lands_inside_the_frame_with_positive_extent` |
| `from_corners` stops sorting its corners | `test_from_corners_does_not_care_which_corner_came_first` |
| `snap` returns a grid point plus one | `test_snap_is_idempotent` |
| `next_default_name` tries one candidate instead of looping | `test_next_default_name_never_collides` |

All four failed; none escaped.
