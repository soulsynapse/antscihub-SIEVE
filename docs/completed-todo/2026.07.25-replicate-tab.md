decisions:
  - what: the viewport is a plain QWidget + QPainter, not napari
    why: ~150 lines and full control of letterboxing and ROI overlay; napari earns its place at the three-way preview overlay or not at all
  - what: decode runs on a QThread worker, never on the GUI thread
    why: a 68 ms seek on the GUI thread is a 68 ms freeze, and the budget is about the UI never blocking
  - what: every edit is a QUndoCommand
    why: ROI geometry is data a user will iterate on; an edit that cannot be undone is an edit they will not risk making
  - what: 4 import-linter contracts wired into `nox -s checks`
    why: the GUI-out-of-the-science boundary is a claim, and an unchecked claim about layering is false within a month
