decisions:
  - what: one filter with a signal parameter, not two filters
    why: shared state, gradient, and reduction; the tab's quick-switch swaps the parameter in place — same card, same bands
  - what: scale and fps as explicit params with auto_block/resolve_block/grid_shape exported
    why: the kernel cannot ask the graph what rescale did; one home for block resolution is what keeps the grid and the count-threshold denominator agreeing
  - what: grayscale conversion at the top of this kernel
    why: v1 converted inside its preprocessor; putting it here keeps rescale/normalize layout-agnostic and matches normalize's gray-projection statistics
  - what: flow path forms five products, not six
    why: the LK solve never reads tt; v1 formed it because its channel plan could also want change from the same pass
  - what: block-mean uses ceil-division grid with NaN-pad + nanmean edges
    why: v1's include_partial=True extraction semantics — an edge block averages the pixels it actually covers
