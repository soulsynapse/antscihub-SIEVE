# Block-signal extraction filter

Item 3 of `docs/filter-tab-parity-plan.md`. v1 semantics intact: sigma=2.0
Gaussian blur as the tensor window, per-pixel LK solve with |det| <= 1e-6
returning exactly zero, speed in px/s via *fps, solve before reduction so
the aperture problem is not coupled to block size.

**What was checked by mutation.** The static test fails if the seed frame
emits anything but zeros or if state leaks between runs. The translation
test fails if the solve's sign convention flips (speed halves) or the fps
scaling is dropped. The aperture test fails specifically for a near-zero
divide — replacing the guard with a plain divide produces enormous values,
not small ones. The grid test pins the three numbers that denominate the
count threshold.
