# Coherence as a third block signal

The item's "one thing to not get backwards" — reduce the tensor, then
eigendecompose — is pinned by the opposing-halves test rather than by the
translation test, and the reason is worth keeping: a swapped implementation
still scores uniform translation 0.87, because locally everything *is*
coherent. Only a block containing mixed motion directions distinguishes the
orders (0.010 vs 0.496). The translation and flicker tests pin the two poles
of the discriminant; the opposing-halves test pins the ordering constraint.

Mutation checks: dropping the zero-change gate fails the static test
(coherence reads 1.0 on a changeless textured block); swapping reduction and
decomposition fails the opposing-halves test as above; reading the top
eigenvalue pair instead of the bottom fails the translation test at 0.156.

The spec deviation is the one thing a future reader will trip over first, so
it lives in its own finding —
`docs/findings/2026.07.26-the-specs-coherence-formula-fails-its-own-test.md` —
and REFINED-VISION **B** carries a dated correction note pointing there
rather than a silent edit.
