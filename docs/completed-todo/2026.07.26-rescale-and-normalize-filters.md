# Preprocessing filters

Item 2 of `docs/filter-tab-parity-plan.md`. Both `.md`s are written for the
wizard's guidance pane (plan learning 7): the summary line becomes the row
blurb, "When to use it" and "What it does not do" become the pane.

**What was checked by mutation.** The BGR test's channels have deliberately
different per-channel means, so pooled-channel statistics fail it while
gray-projection statistics pass — it can tell the two implementations apart,
which is the point. The rounding test uses 53x101 so `round` and `floor`
disagree on one axis. The identity tests compare objects (`is`), not pixels,
so a copy on the no-op path fails them.

**Outside the item's scope.** cv2's stubs reject scalar operands to
`cv2.multiply`/`add`, so the fused affine is numpy (`np.multiply` with dtype
plus in-place `np.add`) — same two SIMD passes, no temporaries beyond the
one output.
