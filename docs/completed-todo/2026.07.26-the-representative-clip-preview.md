# ---- the load-bearing part ------------------------------------------------
decisions:
  - what: no invalidation pass — the store outliving the revision *is* the mechanism
    why: node keys already fold in upstream keys, so a suffix walk would be a second answer to what a key covers
  - what: "`measure` is an injected `Callable[[str], AbstractContextManager]`, not a `MetricBus`"
    why: "`sieve.bench` sits above `sieve.pipeline`, so this module may not import the table it is measured against"
  - what: required rather than defaulted, so no call site can render un-instrumented
    why: the two budgets are the only thing that says whether the preview works
  - what: budget keys are string literals here, checked against `BUDGETS` from the test layer
    why: the same layer boundary; `MetricBus.publish` refuses an unknown key, so a typo fails on the first real render
  - what: coalescing stays in `sieve.gui` and is not used here
    why: "`gui/coalescer.py` is above this layer, and a headless render has nothing to discard — see the body"
  - what: "`slider_to_preview` around the first frame, `full_preview_render` around all of them, nested"
    why: two questions about one render — when the user sees something, when they have seen everything
  - what: a one-frame render publishes only `slider_to_preview`
    why: a cheap sample in the 3 s series would improve the median of the thing that measures a whole window
  - what: "`set_window` and `set_replicate` keep every stored entry"
    why: a key carries the node, params, ROI, and backend, and never the span
  - what: the consumer is called inside the timed spans
    why: matches what `player.py` publishes for a scrub; both budget labels say "repaint"
  - what: extracted `cli/common.py` — refuse, load_project, parse_span, span_for
    why: "`sieve preview` was the second command to load a document and parse a span; two spellings would be two spellings of every error message"
  - what: the timings report prints `Budget.key`, not `Budget.label`
    why: the labels carry an arrow and an en dash from ARCHITECTURE.md, and a cp1252 Windows console raises UnicodeEncodeError on them

rejected:
  - what: an explicit `invalidate(node_id)` / suffix walk on the session
    why: "`cache_key.py` already produces the behaviour; a second derivation of it could only ever disagree"
  - what: eviction of the keys an edit orphaned
    why: "`cache.py`'s deferral still holds, and the dead keys are *knowable* (old revision's keys minus the new one's), so it will be garbage collection rather than a policy when it is measured"
  - what: a `tests/bench/` benchmark of the two budgets on the synthetic fixture
    why: it would pass at ~1% of budget on 160x120 and pin nothing; `sieve preview --check` on the reference footage is the gate that means something
  - what: cancellation (a predicate, a flag, a generator to abandon)
    why: the caller holds one render in flight because that is what coalescing requires, and `player.py` has no cancellation either — the in-flight decode was never recallable

measurements:

  results:
    - cold full_preview_render, stateless two-node chain: 1350.2 ms

    - cold with a stateful tail (90 frames of lead-in, 150 decoded): 3281.8 ms — over budget
    - implied cold cost per frame of decode_range: 22.5 ms and 21.9 ms across the two graphs
