decisions:
  - what: count threshold denominated as a fraction of region blocks, converted in count_band_to_counts only
    why: deletes v1's rescale_count_band re-denomination (a measured 13x foot-gun) — a fraction survives a grid change by meaning the same thing
  - what: detect_gate returns bool, not v1's float 0/1
    why: the gate is a predicate; every v1 consumer compared against 0.5 to recover the bool
  - what: morlet_band_power ported alongside morlet_power despite not being named in the item
    why: it is the memory-bounded path a whole-clip pass needs, and its pad-to-the-bank's-support trick is exactly the kind of semantics that gets re-derived wrongly later; a test pins bit-for-bit equality with the cube slice
  - what: scipy added to core deps
    why: float32-preserving FFT, next_fast_len, and threaded workers — v1 measured ~10x over numpy.fft on (T, B) series
  - what: scipy.fft's untyped stubs contained in three cast wrappers
    why: strict pyright sees tuple[Dispatchable]; one contained spot rather than casts through the transform code

rejected:
  - what: porting largest_clump_per_frame
    why: needs cv2, which core forbids, and nothing in the nine parity goals consumes it; it returns with the whole-video pass if that ever lands
  - what: porting v1's None/±inf/float three-valued band encoding
    why: unset-means-disarmed is tab state (the tab does not call detect_gate); core functions take floats with inf legal
