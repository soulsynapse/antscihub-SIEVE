# Agent workflow tooling

The item inverted mid-flight, on purpose. It was scoped as "measurement tool,
then the scoped gate the measurement would presumably justify" — and the
measurement's whole value was that it refused to justify it. The finding holds
that story; this entry exists so the *tools* have a home entry.

**What was checked by mutation.** The residual-attribution test began life
asserting that thinking time after an hour-long idle gap is attributed to the
next call's phase; the implementation deliberately drops it (indistinguishable
from the absence), and the failing assertion was corrected to pin the drop
rather than the guess. The miner also shipped with a real bug caught before
first run: `covered_until` never advanced inside the attribution loop, which
would have counted every pre-call gap from session start and inflated residual
severalfold — the unit test in `tests/unit/test_transcript_stats.py` now fails
if that regresses.

**Outside the item's scope.** TODO.md's thirteen bug bullets were tagged
`(noticed <=2026.07.27)` — they predate the tagging rule the new hygiene test
enforces, and the honest tag is a bound, not an invented date. The bug
section's instruction line now states the machine-checked format.

**Bootstrap note.** `docs/completed-todo/` entries written before this item
were typed by hand from `_TEMPLATE.md`; this entry is the first scaffolded by
`tools/complete_item.py`, including its own file lists.
