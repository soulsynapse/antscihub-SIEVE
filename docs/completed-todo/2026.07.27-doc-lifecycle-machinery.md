# Doc lifecycle machinery

The binding-surface rule this lands under is now written in `CLAUDE.md`: only
the seven rules and CI bind; everything else is evidence. The v1 docs repo is
the cautionary exhibit — nineteen ADRs prescribing subprocess workers,
structlog, DuckDB, Zarr, and CuPy before a line of v2 existed, each one a
standing constraint the agent tried to satisfy. The migration plan, the drift
reporter's never-fail design, and the record banners are all that lesson
applied in three directions.

**Checked by dogfood rather than mutation:** this entry was produced by
`complete_item.py`'s fresh-mode path; the move-mode path is exercised the
first time an item file completes (the migration item instructs exactly that,
so the path is proven before the system is relied on). The first
`doc_drift.py` run flagged five findings with 4–12 commits of file movement —
the report was earning its keep before it was committed.

**Exemplars for the migration:** `docs/todo/sink-writers.md` (deferred,
migrated verbatim from LATER.md) and `docs/todo/the-motion-history-filter.md`
(open, moved from TODO.md). TODO.md keeps the bug list and the what-exists
table and nothing else.
