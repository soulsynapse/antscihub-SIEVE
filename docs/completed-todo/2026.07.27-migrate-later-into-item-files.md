decisions:
  - what: >
      Every "the entry above/below" was rewritten to name a file, and nothing
      else in any body was touched.
    why: >
      Position-relative references are the one thing atomization breaks — after
      the move there is no above. Rewriting them was licensed; rewriting
      anything else was not, because the bodies carry constraints (the
      unexamined-versus-quiet collapse, the decimator's anti-alias, marks
      belonging to a replicate) that cost a day each to re-derive and nothing
      to preserve verbatim.
  - what: >
      Click-through navigation and Materialization stayed two files that link
      each other, as did Coverage lanes / Annotation spans / Accuracy feedback.
    why: >
      Each pair argues it is "one item approached from both ends", which is a
      judgment about scope to be made when the work is taken, not silently
      during a migration. Two linked files preserve the claim; one merged file
      would decide it.
  - what: >
      `render_state`'s LATER.md section counter was deleted rather than left
      behind its `if later.exists()` guard.
    why: >
      It was migration scaffolding whose job is done. Dead code guarded by a
      file that can never exist again is a reader's false lead in the one
      generator that everything else trusts.
  - what: >
      Every path in every `reads` list resolves from the repo root, including
      the three V1 files, which are written as
      `../antscihub-optical-flow-detector/gui/...` rather than as the body's
      prose "V1 `gui/marks_store.py`".
    why: >
      `reads` is the list you open before the first edit, so a name that no
      tool can resolve is not an entry in it — it is prose in a field that
      claims to be data. The bodies keep the prose form in their `Read:` lines,
      which is where an annotation belongs. `replicate-status-columns.md` had
      no `Read:` line to derive from, so its list is the files its own body
      cites; that is the one list in the folder not transcribed from a source
      line, and it is named here rather than left to be discovered.
