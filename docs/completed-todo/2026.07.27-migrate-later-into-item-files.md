# Migrate LATER.md into item files

Mechanical, and the diff carries all of it. Two things the diff does not say:

`docs/.state.md` now lists **18 deferred items against 3 open** — that ratio
was invisible while the deferred half lived in one 683-line file, and it is the
first thing a session sees. The value of the migration is exactly that: a
trigger is only useful if it is next to the thing it fires into.

Outside the item's scope, five files that pointed at `docs/LATER.md` had to be
repointed at specific items rather than at the folder — `ARCHITECTURE.md`
(six references, four of them rule-6 examples that name their entry),
`AUTO-GUARDRAILS.md`, `SCAFFOLD.md`'s projected tree (eight annotations),
`README.md`, and two source comments (`bench/budgets.py`'s `WITHOUT_PRODUCER`
note, `gui/timeline_bar.py`'s `STRIP_HEIGHT`). Each now names a file that a
grep can check, which the old `LATER.md "Application config"` form could not.
