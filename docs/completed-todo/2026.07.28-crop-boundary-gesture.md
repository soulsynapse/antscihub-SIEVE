# The crop boundary in the chain-stack

Built as the item specified, with the source of truth for the record set moved
one layer down from where the item assumed it — see the first decision.

**What the tests pin, and why each fails for its own reason.** The stale/absent
pair is asserted from the state *and* from the reason text, because a card that
collapsed them would still pass a test that only checked "not at rest". The
viewport claim is driven as a drag and asserted on `roi_adjusted` never firing —
the shape `test_an_unselected_box_has_no_handles` already uses — rather than
read off `_handle_rects`, so it survives a refactor of how handles are
suppressed. The write-pass test asserts `runner.paused` *inside* the
`waitSignal` block and `not runner.paused` after it: either assertion alone
passes for a version that never paused, or for one that never resumed.

**One nuance the diff does not show.** `crop_binding.frozen_span` is built on
`CropArtifact.backs`, which deliberately excludes the span — so a record whose
window has widened past the cut reads STALE on the card while still fencing the
clip. That is coherent and deliberate rather than a leak: the remedy for that
staleness is to bring the clip back inside the cut, and the fence is what points
at where. The box freeze is AT_REST-only, as the match-reading item settled.

## The item as written

The front half of click-through navigation, narrowed to the one boundary whose
writer now exists: the *source* boundary. The chain-stack gains a card above
`SPATIAL_PREP` standing for what the graph consumes — this replicate's crop of
the source — and that card is where its at-rest state lives and where
materialization is offered. The full design (descent through *node* output
boundaries, fading ancestry, sibling branches, suggestion machinery) stays in
docs/todo/click-through-navigation.md, deferred with general materialization.

The four states and their register: **not at rest** offers the cut with the
honest price on the affordance itself, where the slowness is felt rather than in
Preferences; **writing** shows progress over the span and cancels to nothing;
**at rest** is quieter than an offer and calmer than progress, because it is the
goal state and not an alert; **stale** names the clause that missed and must not
look like never-cut — an artifact that was cut and then orphaned is a different
claim from one that was never cut.

Materialize is a decision, not a nicety: under the child-source identity model
the artifact is its own source and descending onto it re-keys downstream work,
so the control is a click on a labelled control and never a side effect of
navigation. Compaction stays user-initiated.

Faded means frozen: while a matching artifact backs the replicate, the inputs
that would orphan it — the ROI, and the clip handles beyond the recorded span —
render faded, and faded binds behaviour. Unfreezing is an explicit discard, one
confirmation naming what is discarded, never a silent invalidation.
