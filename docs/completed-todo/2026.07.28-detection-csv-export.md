  `sieve detect --csv` writes the detector's per-frame series and its
  intervals as two CSV files, so a measured detection now leaves the process
  as data a harness or R can read rather than only as a printed summary.

settled:
  - what: a detection leaves the process as two tables, not one
    where: '`src/sieve/detect/tables.py`'
    do_not_redecide: >
      The series is what was *measured* and the intervals are what the current
      `DetectorSettings` *claims* from it; a re-tune moves the second and
      leaves the first untouched. One wide table would make a threshold change
      read as a new measurement. Both are long-form, keyed by `replicate` and
      `node`, so a batch is one file per kind and not one directory per arena.
  - what: absence at the filesystem boundary is a missing file and an `NA`, never an empty one
    where: '`src/sieve/detect/tables.py` `write_tables`, `ABSENT`'
    do_not_redecide: >
      Rule 6 reaching disk. A disarmed detector writes no `intervals.csv` at
      all, because a header-only one is indistinguishable from armed-and-found-
      nothing; an *armed* run with no intervals writes the empty file, and the
      choice keys on armed-ness rather than row count precisely because the two
      collapse for every input a first implementation is tried against. `gated`
      is `NA` when disarmed, not `FALSE` — the detector did not decide the
      frame was quiet, it did not look. A project with no detector is refused
      before decode, since `count` is derived through the value band and so
      there is no series either.
  - what: exported numbers are `repr`, not a fixed-width format
    where: '`src/sieve/detect/tables.py` `_number`'
    do_not_redecide: >
      These tables exist to be diffed against a later run
      (`docs/todo/parity-comparison-finding.md`). A format that agrees to six
      decimal places is a comparison that cannot fail; `repr` round-trips and
      `float32` widens to `float64` exactly.
  - what: '`sieve detect --csv` is not the `Project.Sink` writer and does not relieve it'
    where: '`docs/todo/sink-writers.md`'
    do_not_redecide: >
      This writes the *detector's* output, computed outside the graph with a
      producer that already exists. `Sink` remains gated on a filter emitting a
      `TableSpec`; nothing does, so `cli/run_cmd.py` `_refuse_sinks` stands.
