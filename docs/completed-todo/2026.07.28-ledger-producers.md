# The memory ledger has no producer, and the worker split has no sensor

Built exactly as the item's four-point list asked: a memory producer
(`core/machine.process_memory_bytes` vs `concurrency.ledger_ceiling`), a
pool-utilisation producer (`core/pool_meter.PoolMeter` in all three pools,
read by `gui/resource_probe.ResourceProbe`), mode on every sample, and
`SENSED`/`WITHOUT_SENSOR` held to the tables by
`tests/unit/test_ledger_sensors.py` the way `WITHOUT_PRODUCER` is held to the
budget table.

Outside the item's scope, nothing changed. The gate note that belongs here
honestly: `nox -s checks` on this machine fails on
`tests/bench/test_density_rebuild.py`, before and after this change alike —
the deterministic full-collection failure `docs/todo/
budget-checks-under-ambient-load.md` already documents (reconfirmed at clean
HEAD in a fresh worktree). Everything else in the gate, including the five new
tests, is green.

## The item as written

Both halves were the same defect: `bench/budgets.py` enforces rule 4 for
latency and holds its gap honest in `WITHOUT_PRODUCER`, while
`gui/concurrency.py` declared three worker pools and four memory shares of
which **not one row had a producer**. `PREVIEW_WORKERS = 2` was the measured
optimum on one machine applied as a ceiling everywhere;
`DETECTOR_WORKERS = 2`'s docstring called itself "a judgement, not a
measurement". No session on any other machine could produce evidence for or
against any of it.

Observability first, not adaptive allocation, for a control reason: a loop
closed around an unobserved plant does not converge, it oscillates, and an
oscillating allocator is worse than a fixed constant wrong by 20%. Rule 7
raised no objection — worker counts and memory shares change where a result
lives and how fast it arrives, never what it is.

This did not retire `docs/todo/ledger-measurements.md`: H3/H4 want a
constant on specific hardware, this built the sensor every session runs, and
the sensor is how the constant gets checked later. It did fire the trigger on
`docs/todo/slow-path-surfacing.md`, which was gated on "nothing to aggregate
until something publishes" — promoted to open in the same commit.
