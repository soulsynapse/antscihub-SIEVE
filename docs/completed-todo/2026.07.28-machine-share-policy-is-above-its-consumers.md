summary: >
  Rule 5's ledger dropped below the things it governs: `core/shares.py` holds
  the worker constants, `WorkerSplit`, `MemoryShare`, the four shares,
  `SENSED`/`WITHOUT_SENSOR` and every function over the byte column, while
  `gui/concurrency.py` keeps only what an interactive session decides —
  `total_workers`, `fits_machine`, `resolve_worker_split`. Eleven modules and
  three ARCHITECTURE.md passages were retargeted off the old home.

decisions:
  - what: "the invariant `gui/concurrency.py` argued for — that `core/` holds no
      policy about sharing a machine — was kept, and restated at both ends"
    why: "the old docstring applied it to *location* when it is about
      *defaults*, and the two come apart: a declaration being reachable from
      below does not make anything below apply it. Unreachability was enforcing
      the right rule by accident. `core/shares.py` declares, the caller applies,
      and a required `workers` argument with no default is what makes the caller
      say which it is."
  - what: "`SENSED` and `WITHOUT_SENSOR` followed the table into `core/shares.py`
      even though their producers (`PoolMeter`, `gui/resource_probe.py`) stay
      above"
    why: "they are statements *about the rows*, so splitting them from the rows
      would declare rule 4's honest gap in neither file — the sum would read as
      complete in one place while the missing sensor was recorded in another.
      This is the arrangement `bench/budgets.py` already has."
  - what: no re-exports from `gui/concurrency.py`
    why: each name keeps one home; six import sites and four test modules were
      updated instead
  - what: "one of the item's three symptoms does not survive inspection"
    why: "it claimed `decode/quiet.py` and `bench/retention_trace.py` refer to
      the table in prose *because they cannot import it*. Neither wants to —
      `quiet.py` cites concurrency's argument as an analogy for fd-2
      redirection, and `retention_trace.compare` explains why a single byte
      figure would report one point on a curve it is sweeping. Both are
      rhetorical citations, so the item's \"become imports if the move makes
      them possible\" step had no work in it. Symptom 2 carried the change
      alone: `detect/detector.py` could only name `DETECTOR_WORKERS` in prose,
      and a constant named in a docstring is one nobody's type checker follows."

rejected:
  - what: "leaving the table in `gui/` and having `detect/` keep citing
      `DETECTOR_WORKERS` in prose"
    why: "`sieve.detect` is below `sieve.gui` in the layer contract, so the
      citation could never become an import, and a shared-resource constant
      that only prose connects to its consumer is exactly the failure rule 5's
      second mechanism exists to prevent"
