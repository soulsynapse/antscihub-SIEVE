---
title: Take the save prompts out, now that rollback exists
date: 2026-07-28T00:40:10-07:00
commit: "17de56f"
tags: [gui, project-io, history]
settled: none

summary: >
  Every path that drops the document — opening a video, opening a project,
  closing the video, closing the window — now proceeds without asking, and the
  last edit before it reaches the history instead of the bin.

files:
  added: []
  changed:
    - src/sieve/gui/history.py
    - src/sieve/gui/main_window.py
    - tests/gui/conftest.py
    - tests/gui/test_project_io.py
  removed: []

decisions:
  - what: >
      `close_video` flushes its pending snapshot instead of stopping it, which
      the item did not ask for.
    why: >
      Dropping it was correct only while a prompt stood in front of the path —
      the zero-interval timer would otherwise have fired after `unbind_source`
      and snapshotted the emptiness the close produced. Deleting the guard
      without moving the flush would have left `close_video` as the one path
      where the net does not catch, which is the exact failure the ordering
      argument existed to prevent. The flush goes above the close and the
      `stop()` below it stays, so the emptiness case is still covered.
  - what: >
      `save_project` and `save_project_as` keep their `bool` returns even though
      no caller reads them now.
    why: >
      A Save the user backed out of at the file chooser and a Save that wrote a
      file are different outcomes, and the return value is the only place that
      difference is stated. Dropping it would trade a live distinction for four
      characters.

rejected:
  - what: >
      Keeping the fixture's declared-clean dance in `tests/gui/test_project_io.py`
      teardown.
    why: >
      It existed because a refused close never reached `_player.shutdown()` and
      the decode thread then outlived the QApplication. Nothing can refuse a
      close any more, so the line asserted a hazard that no longer exists —
      leaving it in would have read as a live precaution.
