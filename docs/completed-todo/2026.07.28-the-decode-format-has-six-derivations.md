summary: >
  The decode format has one home per run and a disagreement is loud:
  `RenderRequest.luma` is a field derived in `PreviewRunner._request` (now the
  only constructor), `ExecutionPlan.luma` carries it for anything holding a
  plan, and `executor._check_format` raises `FormatMismatchError` on every
  decoded frame whose format disagrees with the plan its keys were built from.

  removed: []

decisions:
  - what: the format check runs per frame, not once on the first frame
    why: a reader that changes format mid-run is exactly the case a
      first-frame check cannot see, and the check is one enum comparison
  - what: raising was added although the item did not ask for it
    why: "the item's own \"what breaks if this is wrong\" was *nothing loudly,*
      which is the danger — a format/key disagreement poisons the cache and
      renders a plausible frame. It caught ten tests handing BGR frames to
      luma-keyed plans on the first run."
  - what: "two of the six derivation sites stay — `cli/preview_cmd.py` and
      `cli/materialize_cmd.py` call `graph_needs_chroma` once each"
    why: both must choose a format before they have a plan, so this is one
      derivation per command rather than a second answer to the same question
  - what: "`test_executor_run`'s four-distinct-frames assertion was weakened to
      three, with the reason stated in the test"
    why: "conftest's synthetic video marks frame *n* in the blue channel, BT.601
      weights blue at 0.114, so one frame of separation is ~0.6 luma levels —
      inside mp4v's own error. CLAUDE.md's claim that a test can assert *which*
      frame a seek landed on is now true only on the colour path, and a fixture
      whose marker survives both formats is its own item."

rejected:
  - what: leaving the two render-thread derivations in place because the cost
      is negligible
    why: "measured first, as the item asked — `graph_needs_chroma` is 8.9 us
      median over a three-node chain and the render thread paid ~18 us inside a
      3000 ms span (docs/findings/2026.07.28-the-decode-format-is-free-to-derive.md).
      The cost half is nothing; the correctness argument carries the change on
      its own."
