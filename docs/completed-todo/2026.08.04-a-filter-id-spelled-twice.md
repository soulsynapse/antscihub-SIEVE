summary: >
  A registered filter id typed outside the module that registers it now fails
  the suite unless it is on a shrink-only list of eleven `(module, filter_id)`
  pairs, which closes rule 3's data-shaped hole beside the import-shaped one it
  already checked; a second, deliberately vacuous check governs `TableSpec`
  column names from before the first table emitter exists.

# Rows a later item must not re-decide, or the word `none`. Generated into
# docs/SETTLED.md; this is the only thing that writes it. Answering `none` is
# the common case and is a real answer — leaving the marker is not.
settled:
  - what: Where a filter-id exception list may live
    where: "`tests/unit/test_filter_id_spelling.py`"
    do_not_redecide: >
      In the test, not in `src/`, which is the one place `WITHOUT_PRODUCER`'s
      shape does not carry over: a list of filter ids in a module under
      `src/sieve/` would be eleven foreign spellings of its own and would trip
      the check it declares.
  - what: What the duplicate-literal check is aimed at
    where: "`tests/unit/test_filter_id_spelling.py`"
    do_not_redecide: >
      Registered filter ids and declared `TableSpec` column names only — never
      every string across a layer boundary. A generic two-layer detector seeds
      an exception list the size of the codebase (`"in"`, `"array"`, every
      StrEnum value), which is enumeration rot re-encoded in Python.
  - what: How a filter's owning module is determined
    where: "`tests/unit/test_filter_id_spelling.py`"
    do_not_redecide: >
      Asked of the registered params class via `inspect.getfile`, never derived
      from `filters/<filter_id>.py`. The convention holds for all seven filters
      and nothing enforces it, so assuming it would make the check silently
      wrong for the first filter that breaks it.
