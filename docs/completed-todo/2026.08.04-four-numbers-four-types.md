summary: >
  Media time, wall time, work units and frame counts became four types in
  `core/types.py` with no implicit conversion between any two, and the warmup
  arithmetic — spec declaration, params refinement, the per-node conversion, the
  plan's fold, and `ExecutionPlan.lead_in` — now runs in `FrameCount` end to end,
  so a count and a duration can no longer be added.

settled:
  - what: The four quantity types, and which of them may be negative
    where: '`src/sieve/core/types.py`'
    do_not_redecide: >
      Only `FrameCount` is a count and only it refuses a negative value; wall
      time, media time and work units keep their sign because a headroom below a
      limit is a real reading and clamping it would make "just made it" and "made
      it by a mile" the same number. `FrameCount` therefore has no `__radd__`,
      which is what makes `sum()` over per-node warmups — the plain-sum error
      `source_warmup_frames` exists to prevent — unwritable rather than merely
      wrong. `WorkUnits` deliberately carries no conversion to `WallTime` and no
      `.milliseconds`: the divisor belongs to one machine and one backend, and
      naming it is `work-units-have-one-anchor`'s job, not this type's.
  - what: Why media time is rational, stated as the arithmetic that fails
    where: '`src/sieve/core/types.py`, `tests/unit/test_quantities.py`'
    do_not_redecide: >
      Not accumulated drift — a float frame duration added a million times is off
      by 1e-6 frames, and the "drifts over a two-hour recording" argument this
      item was written with is false. The failure is that every media time is
      eventually floored onto the frame grid: at 30000/1001, `floor(float(15 /
      fps) * float(fps))` is 14. First failure at frame 15, one whole frame, in
      the first second of footage.
  - what: The enforcement is static, and where the hole in it is
    where: '`src/sieve/core/types.py`'
    do_not_redecide: >
      Mixing two quantities is refused by pyright, not at runtime, because a
      runtime guard would be `reportUnnecessaryIsInstance` under strict and
      returning `NotImplemented` would need a loose `other: object` annotation
      that gives up the static check entirely. Three of the four mixtures happen
      to raise `AttributeError`; `MediaTime + WallTime` does not, because both
      carry `.seconds` — it is caught where it is written and nowhere else. A
      `dict[str, Any]` splat also erases the check, which is how
      `tests/property/test_warmup.py` passed pyright and failed at run time.
