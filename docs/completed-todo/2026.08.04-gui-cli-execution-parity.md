      change energy is constant, the in-band count saturates at the block
      total, and a pinned detection window changes nothing observable. That was
      the first draft, and it passed. `stirred_clip` and its measured
      `VALUE_FLOOR` / `COUNT_FLOOR` exist for that reason and are not
      decoration.
