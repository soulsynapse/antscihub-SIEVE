  Enter or Esc in any spin box now releases the keyboard, so the spacebar plays
  again the moment a typed value is committed or abandoned — the enabled
  Play/Pause action and the working spacebar stopped being two different claims.

settled:
  - what: An edit's exits release the keyboard, not just the edit
    where: "`src/sieve/gui/keyboard_handback.py`"
    do_not_redecide: >
      The handback is deferred by one turn of the event loop and applies to
      `QAbstractSpinBox` only. Clearing focus in place delivers a focus-out,
      which is a commit — Esc would then write the number it was pressed to
      discard. Text fields are out of scope because their Enter and Esc already
      belong to something else (the wizard's search hands Esc up to the wizard).
