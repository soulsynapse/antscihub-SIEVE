summary: >
  The composite grid's heat layer is one image built from band_plot.ramp_lut
  and expanded over grid_edges, so a repaint costs the pane's pixels rather
  than the block count: 34.2 ms to 2.2 ms at B = 16,384, which is the lag
  the heatmap slider bought at any value above zero.
