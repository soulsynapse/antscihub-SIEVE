settled:
  - what: The v6 upgrade lives in pipeline/, not as a model_validator on Project
    where: "`src/sieve/pipeline/upgrade.py`"
    do_not_redecide: >
      Synthesizing a node names a filter — its id, its version, and the
      identity value of its parameters — and core/pipeline_model.py is
      deliberately not registry-aware. A validator there fails
      tests/unit/test_filter_id_spelling.py and costs three permanent
      entries on a shrink-only list. Do not move it back into core; the
      consequence is that the v6 reader also sits above sieve.filters, since
      a document must be upgraded before Project sees it.
  - what: Synthesized node ids are derived from the document, never generated
    where: "`src/sieve/pipeline/upgrade.py`"
    do_not_redecide: >
      crop-<root> and span-<leaf>. Node.node_id defaults to a fresh uuid, so
      an upgrade that let it default would give two machines upgrading one
      file two different documents. A derived id the document already uses
      is refused rather than disambiguated, so one file has one upgrade.
  - what: Every replicate pins its own crop region; the node's baseline is WHOLE_FRAME
    where: "`src/sieve/pipeline/upgrade.py`"
    do_not_redecide: >
      Not the edited_params shape of baseline-plus-deviation. Under v5 no
      replicate's geometry followed any other's, so a later edit to a shared
      baseline would move an arena that never agreed to it. The unpinned
      baseline also means a newly drawn arena opens on the whole frame
      rather than on the last one's box.
