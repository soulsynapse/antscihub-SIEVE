summary: >
  The span is a discovered filter (spec, CPU kernel, guidance markdown)
  reachable through sieve run on a hand-built YAML, with the identity span
  spelled as a range wider than any footage. A filter declares
  selecting=True and overrides ParamsBase.selected_frames; ExecutionPlan
  folds every node's range into span, and decode_range still widens that by
  the lead-in, so the pushdown to the reader changes when a result arrives
  and never what it is. The schema does not move: the GUI keeps writing
  Project.clip, and an integration test pins the two paths to the same
  frames through a stateful filter.
