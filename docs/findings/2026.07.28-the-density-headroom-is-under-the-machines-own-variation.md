# The density headroom is under the machine's own variation

The audit's durable result is separable from the miss that prompted it: **the
statistic a budget check uses is a property of the kind of claim, not a house
style**, and the two kinds already in this suite were right by accident.

- `density_rebuild` is a **capability** bound — can the machine do this at all —
  so the minimum over a batch is the correct reading, and it already used `min`.
- `open_to_first_frame` and `scrub_settle` are **felt latency** — a ceiling only
  the best round meets is one the user misses half the time — so the median is
  correct, and they already used `median`.

Nothing recorded that anywhere, which is how the item came to recommend
best-of-N globally. It is now `BEST` / `TYPICAL` in `tests/bench/gate.py` with
the argument attached, so the next budget check picks its statistic from what
it is claiming rather than from the file next to it.

The 50% slowdown from pre-building retry arrays is the one result that
generalizes past this budget. One array is 600 x 16,384 float32 and the binning
is bandwidth-bound over it, so holding nine resident changed what was being
measured. A fixture that makes the subject slower is indistinguishable from a
regression in the subject.
