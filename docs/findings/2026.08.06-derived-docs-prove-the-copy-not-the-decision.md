# A derived doc proves the copy, not the decision

`doc_index.py`'s own docstring gives the reason for deriving: "v2's SCAFFOLD
annotation was a hand-kept copy of exactly that line, and a declared copy of
derivable state drifts." That is correct and the mechanism does what it says.
The finding is about what the mechanism was silently assumed to also cover.

The chain that matters to a reader is *decision → docstring → SCAFFOLD*. The
derivation welds the second link. The first link is a person typing a sentence
once, at package-creation time, and here it was typed before VISION.md's
component table and ADR-6 existed to be typed from — so the omission is not
carelessness, it is the ordering. That ordering recurs: a package's one line is
written the day the directory appears, and the decisions that enumerate what it
owns land after, which is exactly when nothing re-reads the line.

The failure this produces is not a wrong doc. It is a reader asking SCAFFOLD
where schema v1 lives, getting no answer, and putting `pipeline_model.py`
somewhere defensible — at which point `core_strays()` catches it only because
ADR-6 happens to enumerate the filename. The gate that fires is not the gate
that knew.

`ANNOTATION_LIMIT` is 72 and `core`'s current line is 67, so the omission is
not the column running out of room; a fitting line exists.
