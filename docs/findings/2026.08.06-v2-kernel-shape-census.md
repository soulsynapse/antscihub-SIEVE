# v2 never exercised its kernel dispatch's variability

The dispatch layer's variability axes — four kernel protocols, two backends,
a preference-order `select` — were designed capacity, not observed need: one
backend ever registered, one protocol never implemented, and the three used
shapes differ only in which of `(params, window, state)` they read. The
prediction that would have flipped ADR-2: a filter whose kernel could not be
written as the one signature without the executor learning its `tool_id`.
None exists.
