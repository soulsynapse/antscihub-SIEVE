# One hooks path is shared by three worktrees and resolves in only one

CLAUDE.md already warns that this directory is a worktree and that `.git` is a
file rather than a directory. The sharper hazard is the other half of the same
fact: the *config* is shared and the *tree* is not. `core.hooksPath` is one
string for all three checkouts, and it is relative, so each worktree resolves it
against its own root and gets a different answer — v2 gets a hook, v3 and v2.5
get nothing, and none of that is visible from any file in v3.

The reason to write it down now rather than when a hook is wanted: the loop is
about to make more worktrees, not fewer. CLAUDE.md tells a queued run to take its
own, precisely so two sessions do not commit each other's work. Every one of them
inherits this config and none of them inherits `tools/githooks`.
