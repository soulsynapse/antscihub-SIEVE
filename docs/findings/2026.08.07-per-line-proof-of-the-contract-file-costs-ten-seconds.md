# Per-line proof of the whole contract file costs ten seconds

The expectation this refutes was arithmetic on the wrong term. One red per
contract was six runs; per line is 36, and six times a number nobody had
measured reads as expensive. The measured term is the graph build, which does
not care how many times it is asked and does not grow with the number of
contract lines — 87 files and 338 dependencies each time, whatever the planted
edge is.

What would have flipped this: a lint above two seconds, which is where 36 runs
stops fitting beside a unit suite. `no_cache=True` is the reason the number is
not lower; the cache would answer for a tree at the same path family that is
no longer the tree under test, and 0.26 s is the price of refusing it.
