# temporal_baseline's documented degenerate paths are asserted by nothing

The kill ratio is the point of the shape here, not the failure. 31 of 47 is the
strongest sweep any Phase-4 tool has taken, and the file earns it: the two
medians, the sigma constant, the strided admission, the frame-median floor, the
warmup bound and every field on the params class are each pinned by a case that
moves when they move. Nothing below is an argument that the port was careless.

What survived is one shape three times. Each survivor sits on a branch the
module argues for at length in prose — the ring during its own fill, the frame
with no variation anywhere, the window that is not a whole number of frames —
and in each case the fixtures are built from round numbers that never enter the
branch. A 40-frame series with a 30-frame window is past fill at the frame the
golden pins. A noise field has a positive MAD in every cell but the one
deliberately made constant. Four seconds at 30 fps is 120 frames on the nose.

The allocator probe is what makes the first one more than bookkeeping. If the
partial-fill path were merely untested one would expect `filled = size` to
change some number somewhere; instead it changes nothing, because the slots it
newly reads are `np.empty` and this machine returned zeros for them. Poisoning
the allocator to 99.0 is the prediction that would have refuted the concern —
if any case read a partially filled ring, that mutant alone would fail. It does
not, and it does not fail alongside `filled = size` either. Warmup-era output
is unobserved end to end.

The rounding survivor is the same shape as
[a test named for a semantic is the one nobody mutates](loop/2026.08.07-a-test-named-for-a-semantic-is-the-one-nobody-mutates.md)
arrived at from the fixture side rather than the name side: there `round` versus
`int` survived because no test was named for it, here `ceil` versus `floor`
survives because no window was chosen to disagree. One non-integer window
anywhere in the file closes it.
