# The rescale/normalize file holds under a sweep it did not write

[A test named for a semantic is the one nobody mutates](loop/2026.08.07-a-test-named-for-a-semantic-is-the-one-nobody-mutates.md)
argued that a worker's mutant list is a picture of what the worker was thinking
about, and that the reviewer generating its own list from the source is the half
that matters. This is that half run again after the repair, and it is the first
time in this loop that it came back empty.

That the empty result means something rests on the list not being the run's.
Three of the eight are semantics no document in the repo argues about — the
`ChannelSpec.GRAY` early return, the `scale >= 1.0` boundary at exactly 1.0,
and `out_width` reading the wrong extent — which is the class the previous
finding identified as systematically unswept, because uncontentious is the same
thing as unexamined. Two more, the pooled-statistics mutant and `INTER_LINEAR`,
are the two the module docstrings *do* argue and were the original run's whole
list; they are here as a control, and they still die.

What would have refuted the framing: any mutant surviving inside either `run`.
The two things that do survive sit outside it — a constant's value with no case
in its band, and the `register_tool` arguments, which no tool on the shelf
asserts and which is a separate item rather than this file's omission.
