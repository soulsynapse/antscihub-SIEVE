# The stirred clip survives its encoder

The reason to write this down is that the obvious inference from the first
measurement is wrong. Two files with different hashes look like two different
videos, and the safe-seeming response — commit the mp4 so both sides read the
same bytes — would have put media in the repo against `tests/conftest.py`'s
stated rule, and would have done it to defend against a difference that does not
reach any number the oracle compares.

The 2x2 decode probe is the one that settles it, and it is 2x2 rather than 1x1
on purpose: encoder and decoder are separately versioned here, so a single
round trip inside one environment could not tell "both builds encode the same
picture" from "each build decodes its own file consistently". All four
combinations landing on one hash rules out both.

What this does not license is confidence about the fixture's *content* matching
across the two spellings of it — `REGENERATE`'s inline copy and
`tests/conftest.py`'s. That is a different risk with a different guard: the
oracle's gate comparison fails if they drift, which is stronger than a checksum
would be, because it fails for the reason that matters rather than for any
difference at all.
