# v2's settling frontier ships at half its own measurement

The interesting part is not the number. It is that three documents, one
docstring and one test all exist around this constant and none of them can see
the disagreement: the prose argues 2.0 in detail, the finding records 2.0 as
what was set, the completed item records 2.0 as what was delivered, and the
line of code says 1.0. The test that would catch it computes its own
expectation from the constant, so it is a tautology dressed as a bound — the
same shape as a declaration whose only reader is its own restatement.

For v3 this is a warning rather than a defect. Nothing here is carried, because
the frontier is not a number a caller has to remember to ask for any more: a
centred tool declares `lookahead_frames`, and the executor refuses to emit a
frame until it has read that far past it. But if the settled-frontier machinery
is ever revived — an interactive partial pass that wants to draw a curve past
where it may claim a detection — 1.0 is not the value the measurement supports,
and the test beside it will not say so.
