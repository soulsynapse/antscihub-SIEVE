# The constant-frame guard is output-equivalent to the division it refuses

`image_of` scales a frame between its own extremes, and guards the degenerate
case: `scaled = np.zeros_like(array) if spread <= 0.0 else (array - low) / spread`.
The comment above it argues two things — that the division would be a division
by zero, and that either extreme of the ramp would be a brightness the frame did
not earn. Only the first is true of the code as written.

Take the guard away on a constant frame and the numerator is zero everywhere, so
every cell is `0 / 0`, which is `nan`, which the next line's
`np.nan_to_num(..., nan=0.0)` maps to exactly the zero the guard writes. The
second half of the comment is answered by a line three statements later, not by
the branch it stands over. A test that asserted the frame comes out flat — the
obvious fixture, and the one the item was asking for — would pass under the
mutant and go green for the wrong reason.

The one input on which the two disagree is a constant frame carrying a positive
infinity: `inf / 0` is `inf`, which `nan_to_num` sends to white, while the guard
sends the whole frame to black. Nothing on this graph produces such a frame, and
writing it as the fixture would pin the branch on a case that exists only to pin
it.

So the case asserts the operation and not the picture: the call runs inside
`np.errstate(invalid="raise", divide="raise")`, which is a claim about
arithmetic the module performs rather than about a rectangle it fills. It is a
weaker kind of assertion than the never-upscale clamp beside it — that one
changes the rectangle a user sees — and the docstring says so, because a later
reader who tightens the frame's values into something the ramp can distinguish
should know the colour assertion was considered and could not carry the claim.

What would flip this: any change that stops `nan_to_num` from mapping `nan` to
zero, or a value mapping that gave the ramp a non-zero floor. Either would make
the guard visible in the pixels, and the pixel assertion would then be the
honest one.
