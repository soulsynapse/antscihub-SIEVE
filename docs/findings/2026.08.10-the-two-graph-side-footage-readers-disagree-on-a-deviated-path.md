# The two graph-side footage readers disagree on a deviated path

`33aefe3` removed `Project.source` and put the question "which file is the
footage" into `pipeline/resolve_source.py`, where two functions answer it.
`footage_file` states its rule and argues it: `Replicate.overrides` is sparse
over arbitrary parameter names, so a path parameter deviates like any other, and
a folder of already-cut files is exactly the project that leaves the root's own
`path` empty and carries one per arena — so it tries the baseline first and then
each replicate in document order. `named_footage`, written for the callers that
must not touch disk (the library card's footage line, `gui/app.open_project`'s
handoff to the decode thread), reads `node.params` alone and never sees a
replicate.

That project shape is not hypothetical: it is
`tests/integration/test_crop_serving.py::TestAFolderOfAlreadyCutFilesNeedsNoRecord`
verbatim — a `footage` root with no `path`, two replicates each overriding it.
`sieve run` over it decodes and exits 0. The same document on the shelf draws a
card that says the project names no footage, and opening it opens no player.

What makes this a finding rather than a bug report is that `named_footage`'s own
docstring enumerates the states it collapses — "a source nobody has chosen a
file for and a graph with no source root both come back empty, which is one
state to the person looking at the shelf" — and this is a third state it
collapses into the same empty string, which is *not* the same state to that
person. The docstring is the evidence the case was not considered rather than
considered and ruled on, so a later reader deciding what the card should say has
no prior ruling to overturn.

The reason nothing went red is worth naming beside it: every reader of the card
and the player was migrated in the same commit that wrote both functions, and
each fixture names its footage in the baseline. A corpus rewritten to be green
against new code cannot see the branch that code did not take — the item-level
form of
[one red per contract certifies the contract, not its lines](loop/2026.08.06-one-red-per-contract-certifies-the-contract-not-its-lines.md).
