Demuxing every packet (decoding nothing) and flagging keyframes costs 2.57 s
for the whole 5.3K file (11,328 packets, 3.4 GB) and 0.09 s for the small
clip (30,579 packets). The index it yields: the GoPro HEVC file's GOP is
*fixed at 24* (472 keyframes, min=median=max), and the small H.264 clip's is
240–250.

This retires "the GOP is variable so we cannot know" for this footage class,
prices the index every seek policy and filmstrip pre-pass wants at
open-the-file cost, and supplies the datum the seek finding's GOP-replay
explanation rests on. Note the fixedness is a property of the encoder that
made the file — the index is cheap enough to build per file rather than
assumed.

## How to recreate

```
uv run --group experiments python experiments/decode-experiments/04-keyframe-index.py
```
