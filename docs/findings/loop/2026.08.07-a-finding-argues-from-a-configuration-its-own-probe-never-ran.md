# A finding argues from a configuration its own probe never ran

The shape is narrower than "an unsupported claim", and that is what makes it
survive review. Everything checkable checked out: the criterion was green, the
mutants were killed, the one declared survivor genuinely survived, and the
conclusion the finding reached was true. The only defect was that the sentence
carrying the argument and the row carrying the evidence described different
parameter values of the same tool, and neither said so.

A reviewer re-running the criterion never sees it, because the criterion runs
defaults too. It surfaced here only from reading the table against the prose and
noticing the number pointed the other way — then setting the parameter the prose
implied and running it.

The tell is a finding whose argument turns on a tool *doing* something —
cropping, scaling, reducing — where the probe is a generic sweep. A generic
sweep runs defaults, and a default is chosen to be inert. So the very
configuration a semantic argument needs is the one such a sweep is least likely
to have run.

The inverse error is the one worth naming beside it. Because all six preserving
tools emit what they consumed at their defaults, the rule the finding *declined*
to write — "preserving means the count is unchanged" — is green on today's
shelf. Had the run written it, every gate would have passed and the rule would
have stood until the first pipeline cropped anything, at which point it convicts
a correctly declared tool. A rule green on every shipped default is weaker
evidence than a rule green on a chosen one, and reads as stronger.
