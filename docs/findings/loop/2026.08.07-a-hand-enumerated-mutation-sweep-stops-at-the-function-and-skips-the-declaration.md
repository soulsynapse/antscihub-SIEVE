# A hand-enumerated mutation sweep stops at the function and skips the declaration

The worker's six mutants were well chosen and its report was honest about which
tests moved for which. The pattern is not carelessness — it is that a sweep
enumerated by hand is enumerated from the item's own text, and 04.1's text is
about a region, a clamp, and a byte-identical read-back. `register_tool`'s
arguments sit ten lines away and are not what the item talks about, so nothing
in the worker's reading pointed at them.

That makes the shape predictable rather than random, which is what a reviewer
can use: the fields a diff *declares* are systematically less swept than the
lines it *executes*, because prose describes behaviour. Mutating the
declarations is therefore the cheap first move for a reviewer who has a
worker's sweep in hand, and it is where this one found all five survivors.

What would have refuted this: any of the five killed by an existing case. The
control mutant confirms the suite is not simply inert — swapping the clamp's
two arguments kills six cases.
