# A step number that survived a renumbering is re-derived by every worker that meets it

The review prompt tests a worker that proceeds past a mismatch it calls
clerical: if the intent was not as unambiguous as it claimed, the
reinterpretation is the finding. Here it was unambiguous — two independent
routes land on 03.7 and Phase 2 builds no tools — so the run passes that test.

What the test does not reach is the tree. A dangling reference costs one
derivation per worker that meets it, and it is met once per item, so the cost
scales with how many items carry it rather than with how wrong it is. Nine
carried this one. The report that resolved it went into a transcript; the item
that caused it went unchanged into the next worker's queue. That gap — a
correct derivation with nowhere to land — is why the repair belongs to the
review and not to the run: the reviewer is the session that can edit an item
it is not working on.
