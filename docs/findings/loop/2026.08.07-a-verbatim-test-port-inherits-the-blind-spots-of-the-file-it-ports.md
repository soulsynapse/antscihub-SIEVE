# A verbatim test port inherits the blind spots of the file it ports

The failure mode that
[a re-derivation table certifies v2's coverage, not v3's](2026.08.07-a-re-derivation-table-certifies-v2s-coverage-not-v3s.md)
found was guards v3 added that v2 never had, so no row in the table covered
them. This is the complement and it is harder to see: the guards here are v2's
own, present in both files, argued for at length in a docstring both files
share — and untested in both. There is no missing row. The table, if 04.5 had
kept one, would have been complete.

What makes it survive review is that the worker's account is accurate at every
step, which is the same property that made the `ModuleNotFoundError` proof of
red pass for months. "All six port" is true. "Every algorithmic line is v2's"
is true, and I confirmed it by diff. "The goldens reproduce v2 bit-exactly" is
true, and I confirmed it by re-running the recorded regeneration command inside
v2's environment. Three independent confirmations of fidelity, and fidelity was
never the question.

The prediction that would have refuted this: a survivor whose killing case
exists in v2 and was dropped in the port. There is none — the port dropped
nothing. Every gap is a gap in the source.
