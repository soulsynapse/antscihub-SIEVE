# A consistency guard as a criterion is green on both sides of the work

The near neighbour is
[a criterion drafted from v2's file list names a subject two phases out](2026.08.07-a-criterion-drafted-from-v2s-file-list-names-a-subject-two-phases-out.md),
and this is its mirror. There the criterion was red from the day it was written
and stayed red; a worker reaching it finds it unreachable and says so. Here the
criterion is green from the day it was written and stays green, and the failure
mode is worse: the loop selects the item, the worker runs the criterion, and the
only thing standing between a green baseline and a `done` on unbuilt work is the
worker declining to claim it. This one did decline. Nothing in the tree would
have caught it if it had not.

What makes a test file unusable as a criterion is not that it is unrelated to
the item. `test_budget_producers.py` is *about* `slider_to_graph` — the key is
named in its `WITHOUT_PRODUCER` fixture and in its own pattern case. The
disqualifying property is that both of its checks are equalities between a
declared set and a scan of the tree. An equality between two things the same
commit moves together is invariant under the move: the set and the scan change
in step, so the guard holds before, holds after, and goes red only in the window
where one has moved and the other has not. That is a real and useful check on
the bookkeeping of a transition. It is not an observation that the transition
happened, and an item whose whole content *is* the transition cannot use it.

The item's own prose already named the assertion the command lacked — "the key
moved out of `WITHOUT_PRODUCER` and into `TIMED`" — so the gap here is not that
nobody knew what the outcome was. It is that the outcome was written in prose
beside a criterion that could not carry it, and only the two roles that read the
prose and run the command in the same session (the worker, then the review) are
positioned to notice the difference.

The general form, for a review widening a `done_when`: run the criterion against
the tree as it stands *before* the work, not only after. A criterion that is
green on an unbuilt item is not evidence about the item at all, whichever way
the diff eventually goes.
