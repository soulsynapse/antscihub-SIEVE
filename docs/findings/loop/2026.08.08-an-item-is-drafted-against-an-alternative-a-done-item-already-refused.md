# An item is drafted against an alternative a done item already refused

The loop is good at not repeating work and bad at not repeating *arguments*. A
built thing is visible — the module is there, the test runs, `--next` skips the
row. A refused alternative leaves nothing behind but a paragraph in a file the
selector will never route to again, and the next drafter reaching the same
junction has no signal that anyone stood there before.

What makes this instance sharp rather than merely wasteful is that both
arguments were correct and they were different. The phase-1 item refused a
declared axis on *units*: three bands, three incompatible kinds of quantity, no
enum spanning them. The phase-7 worker refused it on *emissions*: detect's
product list is one gate, and the check that would police the binding has
nothing to catch. Neither subsumes the other, and the second was reached by
reading a registration comment that happened to be unusually candid. Take that
comment away — write `emissions=(Emission("gate"),)` with no prose beside it —
and the worker plausibly implements the clause, `detect` declares `"gate"`
three times, registration passes, and the editor puts frequency handles on a
0/1 trace. The defect would then be a declaration that is verified and false,
which is the exact failure `adr/declared-means-verified.md` was written for,
shipped past the ADR by an item that cited it approvingly.

The near-miss is the finding. This one was caught by a comment, and a comment is
not a mechanism.

What would refute the general shape: a pool where a ruling that closes a door is
written back onto the thing it closes it for. `whether-a-stereotype-declares-an-arity.md`
did that correctly — its ruling became `adr/one-field-is-one-populated-value.md`,
which a later drafter meets through `ARCHITECTURE.md`. The band ruling stayed in
the item, and that is the whole difference in reachability. Not every refusal
earns an ADR; the cheaper form is a sentence in the vocabulary's own docstring
saying what was refused and where, since a drafter proposing a new declaration
is already reading the enum they propose to declare against.

Related: [a criterion drafted from v2's file list names a subject two phases
out](2026.08.07-a-criterion-drafted-from-v2s-file-list-names-a-subject-two-phases-out.md)
is the same cost — a full run spent reaching a conclusion available at drafting
time — with a different detectable signature. That one is read the criterion's
imports; this one is grep the pool for the subject before writing a clause about
it.
