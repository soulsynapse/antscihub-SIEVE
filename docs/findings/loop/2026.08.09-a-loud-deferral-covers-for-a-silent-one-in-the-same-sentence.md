# A loud deferral covers for a silent one in the same sentence

The shape is not "a worker skipped part of an item". It is that the *visible*
deferral is what protects the invisible one. A run that quietly builds two
thirds of a sentence and says nothing invites the question "what about the
rest"; a run that builds two thirds, then argues for a page about why the
remaining third needs a ruling and mints an item for it, has answered that
question in advance with the wrong third. The reviewer's attention goes where
the argument is.

The prediction that would falsify this reading: if the omission were ordinary
inattention rather than cover, the run's account would be equally thin about
both clauses. It is not — the stage headers get two referents compared, a
derivation sketched from `ElementKind`, and a named obstacle in `Dag.build`.
That is a run that read the sentence.

What makes it worth recording rather than filing as one worker's slip is that
the criterion cannot reach it and neither can any criterion of this shape. A
`-k` selector over a file the run wrote is scoped to the claims the run chose
to make; the clauses it declined to build are outside the selection by
construction, and the only reader positioned to notice is a review holding the
item body and the diff at the same time.
