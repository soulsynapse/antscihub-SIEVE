# An item's clause that lands only in paintEvent is outside every oracle

The division that produced this is a good one and is stated in the code:
`FannedEdge`'s docstring says "what the picture claims is geometry, and geometry
is the thing a test can read", which is why `fanned_edge()` returns segments
instead of painting them, and why three of five geometry mutants die. The
failure is at the division's edge. A clause like "left-aligned on the trunk" has
a number behind it and lands inside the tested half; a clause like "numbered
squares" or "the others are the same chain, unwalked" has no number behind it at
all, and the same idiom that rescued the first silently drops the second.

What makes this a loop truth rather than three coincidences is that every
artifact the loop inspects agrees the clauses were built, because they were. The
diff has them. The item body has them. A clause-by-clause read of the body
against the diff — the remedy
[a loud deferral covers for a silent one](2026.08.09-a-loud-deferral-covers-for-a-silent-one-in-the-same-sentence.md)
proposes, and which this review ran — marks them present and moves on. Only a
mutation pointed at `paintEvent` disagrees, and nothing in the review prompt
sends one there: step 3 asks whether the new tests can fail, and these tests
can, on everything they cover.

The prediction that would refute this reading: if the survivors were ordinary
coverage debt rather than a structural blind spot, they would be spread across
the file. They are not — every survivor in the fan is inside `paintEvent` or the
`_paint_fanned_edge` colour choice, and every mutant outside paint that changes
what the picture claims dies.

## 2026-08-09 amendment: the remedy that worked, on a fourth clause of the same file

09.2's collision clause is the same shape as the three above — where a name is
painted has no geometric referent, and `drawText` is the only line that realizes
it — and it did not close blind. The work run exposed `ChainColumn.label_rect`,
the box a name occupies, computed from the same origin the painter is handed,
and the criterion reads boxes rather than pixels. Under an independent sweep at
1a55e31 the lift zeroed, the reserved headroom zeroed, and the reported box width
shrunk are all KILLED; the review's own re-run reproduces all three. The one
survivor the worker argues, `origin.y() - ascent() ==> origin.y()`, moves both
boxes together and is invariant to a claim about their relative placement.

So the answer to this file's second open question — whether the answer is a
fixture at all — has one worked instance and it is neither a `grab()` diff nor a
read-back: the clause was given a geometric referent by exposing the geometry the
paint call consumes, which is the file's own stated division (`FannedEdge`)
applied one level further out. It does not reach the ordinal or the colour, which
have no geometry to expose; it does reach anything positional. What remains
unheld here is the same residue as everywhere else: the boxes are metrics-derived
and the picture is only asked whether ink exists at each box, so a font that
disagreed between measurement and paint would not be seen. `stack_stylesheet()`
sets no font rule, so nothing in the tree makes them disagree today.

## 2026-08-09 amendment: the fan's provisional branch was reachable geometry with no case

09.9's `fanned_edge(dst)` was cited by 09.10's fold as an instance of this file's
shape, and on the re-read it is the adjacent one rather than this one: the branch
was already on the exposed-geometry side of `FannedEdge`'s division — it returns
runs and drops — and what it lacked was a fixture with a fan and a box on screen
at once, because the 09.9 project declared no regions. 09.10's `test_swap_box.py`
builds the pane directly and asserts the rejoin lands on the box's top edge and
the interrupted edge is absent from `painted_edges()`, and a mutation over the
anchored fan suppression is KILLED. So the residue this file names is smaller by
one branch, and the distinction is worth keeping: a clause with no geometric
referent needs the remedy the first amendment records, while a clause with
geometry and no fixture is ordinary coverage debt that the reviewer's
what-would-go-red question already finds.
