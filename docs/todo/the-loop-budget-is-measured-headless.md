# The loop budget is measured headless

Phase 6's gate, and the moment v3 either has its value proposition or does
not: both regimes measured through the preview session on the stirred clip
(05.5), with no Qt in the process. Under budget the number is proven before
a widget exists, so any later regression is the GUI's — over budget, that is
the finding the plan most needs and it stops Phase 7 rather than being
smoothed.

The reading lands as a `docs/findings/` file in the same session, with the
machine it was taken on: a budget test that passes tells the next reader
nothing about the margin, and margin is what decides whether the GUI has room.
The test asserts the budget; the finding records what was actually measured.

The number is compared against `bench/budgets.py`'s table (06.1) and never
against a constant written here.
